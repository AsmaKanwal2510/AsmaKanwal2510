## 01 / About

I'm **Asma Kanwal**, a developer with a designer's eye. I like owning a feature end to end: the database table, the API route, and the button you click.

Graphic design and Figma taught me to care about spacing, colour, and type. Full-stack development lets me bring those details to life — from a considered interface to the server-side logic and data behind it.

I'm completing my **BS in Computer Science at Rawalpindi Women University (2023–2027)** and am available for **internships and entry-level opportunities**.

## 02 / What I do

### ◈ Full-stack web development

I build complete web applications, connecting responsive frontend experiences with backend services, APIs, and relational databases.

### ◈ Frontend development

I create responsive interfaces with React and Next.js, using TypeScript, JavaScript, HTML, and CSS to turn designs into clear, usable experiences.

### ◈ Backend & API development

I build server-side functionality with Node.js, Express, and Python/FastAPI, including REST APIs, authentication, and database-backed features.

### ◈ UI design & implementation

I use Figma and my graphic-design background to think through layout, spacing, colour, and typography — then translate those decisions into working interfaces.

### ◈ AI-assisted development

AI helps me move faster, but I stay responsible for the result: I read and understand the code, use tests to verify behaviour, and review quality and security before release.

- **Faster, not careless.** AI saves time on drafts and boilerplate, so I can spend more time on design and security.
